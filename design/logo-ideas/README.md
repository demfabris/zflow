# zflow logo ideas

Six flat, transparent SVG marks. Each uses a 1024 × 1024 canvas and solid fills.

| File | Idea |
| --- | --- |
| [Ribbon Z](01-ribbon-z.svg) | A single rounded ribbon draws the Z. |
| [Edge Crossing](02-edge-crossing.svg) | A pointer crosses between two computers. |
| [Handoff](03-handoff.svg) | Two cursors pass control in opposite directions. |
| [Slipstream](04-slipstream.svg) | Two broad streams carry input across. |
| [Key Z](05-key-z.svg) | A Z inside one sturdy keyboard key. |
| [Relay](06-relay.svg) | Two computers joined by a diagonal route. |

[Compare the concepts](preview.png). The preview backgrounds are not part of the marks.

For Icon Composer, drag in a complete SVG for a single artwork layer, or import the SVGs in its `layers/` folder separately. Each piece has the same canvas and coordinates; use the filename numbers for the order, with 01 at the back. Set the background and material effects in Icon Composer.

The marks use paths and solid fills, with no fonts, images, filters, gradients, or external assets. Colors are starting points. You can change the fill values directly.

[Apple's Icon Composer guide](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer)
